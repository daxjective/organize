## 경로 바꾸는 법 — 다른 PC 로 옮겨도 그대로 돈다

옛 PC 의 경로(`C:\Users\<옛사용자>\...`)가 코드에 박혀 있던 것을 걷어냈다.
이제 **홈 폴더 기준**이라 사용자 이름이 달라도 그대로 동작한다.

각 스크립트 맨 위에 이 블록이 있다. **여기 한 줄만 바꾸면 된다.**

```python
# ── 경로 설정 · 여기만 바꾸면 된다 ─────────────────────────────
source_path = str(Path.home() / "Downloads" / "a")
```

| 바꾸고 싶은 것 | 이렇게 적는다 |
|---|---|
| 홈 폴더 아래 다른 폴더 | `str(Path.home() / "Desktop" / "정리함")` |
| 다른 드라이브 | `str(Path(r"D:\정리할폴더"))` |
| 휴대폰 사진 폴더 | `str(Path.home() / "CrossDevice" / "내휴대폰" / "storage" / "DCIM" / "Camera")` |

`내휴대폰` 은 실제 기기 이름으로 바꾼다(윈도우 휴대폰 연결 폴더 이름 그대로).

`base_destination = r'F:\day'` 처럼 **드라이브 문자가 남아 있는 줄**은 그 드라이브가
없으면 실패한다. 백업 드라이브를 안 쓰면 그 줄도 홈 폴더 아래로 바꿔 준다.

| 계열 | 파일 | 참고할 부분 |
|---|---|---|
| 압축 해제 | `zipper.py` → `zipper copy.py` → `zipper copy 2.py` | 이름 충돌 시 번호 부여, 해제 후 원본 삭제 흐름 |
| 연도별 정리 | `sort.py` → `test.py` → `move_folder.py` → `202604_update.py` → `result.py` | **`result.py` 가 최종본** — 목적지 해시 선수집, 크로스 드라이브 `copy2` 후 삭제 |
| 중복 제거 | `delete_duplicate.py` → `dup2.py` | 크기+해시 조합 판정 |
| 검증 | `search.py` | (변수 미정의로 실행 불가) |
| 메모 | `정보.md` | 각 스크립트 용도 메모 |

## 새 구현에서 반드시 고친 것

- 파일명 연도 정규식 `(19|20)\d{2}` → `screenshot_1920x1080.png` 를 1920년으로 보냈다
- `os.remove` 직접 호출 → 복구 불가. 격리 폴더로 대체
- 중복 판정이 `os.walk` 순서에 좌우됨 → 명시적 원본 선택 규칙
- 전 파일 해시 계산 → 크기 선필터 3단계
