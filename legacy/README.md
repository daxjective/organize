**실행하지 말 것.** 경로가 `C:\Users\notebiz765\...` 로 하드코딩되어 있는데
현재 PC의 사용자명은 `cloocus` 라 전부 실패한다. 미리보기·되돌리기도 없다.

새 구현의 참고 자료로만 남긴다.

| 계열 | 파일 | 참고할 부분 |
|---|---|---|
| 압축 해제 | `zipper.py` → `zipper copy.py` → `zipper copy 2.py` | 이름 충돌 시 번호 부여, 해제 후 원본 삭제 흐름 |
| 연도별 정리 | `sort.py` → `test.py` → `move_folder.py` → `202604_update.py` → `result.py` | **`result.py` 가 최종본** — 목적지 해시 선수집, 크로스 드라이브 `copy2` 후 삭제 |
| 중복 제거 | `delete_duplicate.py` → `dup2.py` | 크기+해시 조합 판정 |
| 검증 | `search.py` | (변수 미정의로 실행 불가) |
| 메모 | `정보.md` | 각 스크립트 용도 메모 |
