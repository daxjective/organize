# 보류를 무리로 보여주기 · 실행 뒤 비우기

2026-08-28 · organize GUI

## 왜

미리보기의 「보류」 탭이 이렇게 나온다.

```
[✓] 보고서_2.pdf  내용이 같음 · 남긴 파일 보고서_1.pdf   .organize/trash/20260828-105350/보고서_2.pdf
[✓] 보고서_3.pdf  내용이 같음 · 남긴 파일 보고서_1.pdf   .organize/trash/20260828-105350/보고서_3.pdf
[✓] 보고서_4.pdf  내용이 같음 · 남긴 파일 보고서_1.pdf   .organize/trash/20260828-105350/보고서_4.pdf
[✓] 보고서_5.pdf  내용이 같음 · 남긴 파일 보고서_1.pdf   .organize/trash/20260828-105350/보고서_5.pdf
```

네 가지가 걸린다.

1. 「남긴 파일 보고서_1.pdf」에 **어느 폴더인지가 없다.** 같은 이름이 여러 폴더에 있으면 어느 것인지 알 수 없다.
2. 네 줄이 한 무리인데 **묶여 보이지 않는다.** 같은 말이 네 번 반복될 뿐이다.
3. 오른쪽 절반을 먹는 도착 경로는 **전부 같아서 알 필요가 없다.**
4. **열어볼 방법이 없다.**

그래서 "이게 지워도 되는 것인가" 를 화면만 보고 판단할 수 없다.

## 무엇을 비교하는가 — 전제를 바로잡는다

같은 무리의 파일들은 **바이트 하나까지 동일하다.** `hashing.py` 가 크기 → 앞 8KB → 전체 해시 3단계로 거른다. 그러므로 **내용을 비교할 일은 없다.**

판단해야 하는 것은 이것이다.

```
바탕화면/보고서.pdf              2024-03-01   ← 남기기로 정해진 것
문서/2024/보고서_최종본.pdf      2024-03-15   ← 보류될 것
```

**어느 자리, 어느 이름을 남길까.** 근거는 위치 · 이름 · 수정일이다. 그래서 화면이 보여줄 것도 그것이다.

파일을 눈으로 확인하고 싶을 때를 위해 열기는 둔다. 다만 **창 안에서 사진을 보여줄 수는 없다** — 이 프로젝트는 외부 패키지가 0개이고(`dependencies = []`), tkinter 기본 이미지는 PNG·GIF만 읽는다. 사진은 대개 JPEG 다. 여는 일은 OS 에 맡긴다.

## 범위

**한다**

- 미리보기 「보류」 탭을 무리로 묶어 보여준다
- 파일 이름을 누르면 탐색기가 그 파일을 선택한 채 열린다
- 실행 뒤 결과 창에 [보류한 N개 지우기] 를 둔다

**안 한다** (다른 건으로 따로 잡는다)

- 미리보기에서 남길 쪽을 바꾸기 — 이번에는 "짝을 보여주기만"
- 보류 폴더를 무리별 하위 폴더로 묶기 — 비교를 실행 전에 하므로 필요 없다
- 표에서 글자를 끌어 고르기 — `Label` 을 `Entry`/`Text` 로 바꾸는 별개의 일

## 화면 — 미리보기 「보류」 탭

```
┌ 이동 1 ─ 보류 5 ─ 폴더 생성 1 ────────────────────────────────────┐
│                                                                   │
│  같은 파일 5개                                                     │
│  남기는 것  바탕화면/보고서_1.pdf        2024-03-01  1.2MB         │
│  ─────────────────────────────────────────────────────────────    │
│  [✓] 보고서_2.pdf        (최상단)         2024-03-02               │
│  [✓] 보고서_3.pdf        (최상단)         2024-03-02               │
│  [✓] 보고서_4.pdf        백업/           2024-03-05               │
│                                                                   │
│  같은 파일 2개                                                     │
│  남기는 것  사진/IMG_001.jpg             2023-11-02  3.4MB         │
│  ─────────────────────────────────────────────────────────────    │
│  [✓] IMG_001 (1).jpg     사진/           2023-11-02               │
│                                                                   │
└───────────────────────────────────────────────────────────────────┘
보류 5 · 전부 .organize/trash 로 갑니다
```

| | 전 | 후 |
|---|---|---|
| 남기는 파일 | 이름만, 줄마다 반복 | 무리 머리에 **경로·수정일·크기**, 한 번만 |
| 무리 | 안 보임 | 머리줄로 묶임 |
| 위치 | 없음 | 정리할 폴더 기준 상대 위치. 최상단이면 「(최상단)」 |
| 열기 | 없음 | 이름을 누르면 탐색기에서 선택 |
| 도착 경로 | 줄마다(전부 같음) | 표 아래 한 줄 |

### 이름은 링크다 — [열기] 단추가 아니다

단추로 하면 무리 10개 × 6줄 = 60개가 된다. 이 코드에는 이미 *"줄마다 위젯을 서너 개 만들면 창이 몇 초씩 멈춘다"* 는 실측 주석이 있다(`_MAX_ROWS = 200` 이 있는 이유). 경로를 눌러 여는 링크(`_path_link`)는 화면 1·3 에 이미 있어 손에 익은 조작이기도 하다.

### 파일을 실행하지 않는다

다운로드 폴더를 정리하면 중복 `.exe`·`.msi` 가 나온다. `os.startfile("설치.exe")` 는 그것을 **실행한다.** 확인하려고 누른 것이 설치 프로그램을 띄우면 안 된다.

그래서 **탐색기가 그 파일을 선택한 채 열리게** 한다.

| OS | 방법 |
|---|---|
| 윈도우 | `explorer /select,<경로>` |
| WSL | `explorer.exe /select,<wslpath -w 로 바꾼 경로>` |
| 그 외 | 그 파일이 든 **폴더**를 연다(`open`/`xdg-open`) — 선택까지 해 주는 표준이 없다 |

`picker.py` 에 `reveal_file(path)` 를 더한다. 지금 있는 `open_folder` 와 같은 규칙을 따른다 — 윈도우 판단은 `os.startfile` 유무로, WSL 은 `platform.release()` 로.

## 무리 정보가 흐르는 길

```
dedup.py         Action(kind="quarantine", …, keeper=Path)
    │                                    ↑ 남기기로 정한 파일의 절대경로
    ▼
gui_model.py     Row(…, keeper, keeper_at, keeper_mtime, keeper_size, mtime)
                 수정일·크기는 여기서 os.stat 로 읽는다
    │
    ▼
gui.py           group_rows(rows) → [(keeper, [줄들]), …]   ← 순수 함수
                 무리 머리줄 + 줄들을 그린다
```

### `Row` 에 늘어나는 것

| 이름 | 무엇 |
|---|---|
| `keeper` | 남기는 파일의 절대경로. 빈 글자면 무리가 아니다 |
| `keeper_at` | 남기는 파일의 위치(정리할 폴더 기준 상대). 최상단이면 `(최상단)` |
| `keeper_mtime` · `keeper_size` | 머리줄에 적을 수정일·크기 |
| `at` · `mtime` | 이 줄 파일의 위치와 수정일 |

읽지 못하면(`OSError`) 전부 빈 값이다. 줄은 그대로 그린다.

**무리 순서**는 `keeper` 경로의 사전순이다. 무리 안의 순서는 지금 `rows` 순서를 그대로 둔다 — `dedup` 이 정한 순서가 곧 실행 순서다.

### `Action` 에는 `keeper` 하나만 붙인다

`Action` 은 미리보기와 실행이 공유하는 계약이지 화면 표시용 자루가 아니다. 수정일·크기는 싣지 않는다.

기존 `size`/`mtime` 필드가 있지만 그것은 **압축 안의 파일**이라 `stat` 을 부를 수 없어서 있는 것이다. 보류 대상은 디스크에 실재하므로 읽으면 된다. 읽는 자리는 미리보기 스레드 안이라 창이 멈추지 않는다.

`reason` 글자를 파싱해서 남긴 파일을 알아내는 방법은 쓰지 않는다. 문구가 바뀌는 날 조용히 깨진다.

### 줄 수 제한은 무리 단위로 자른다

지금 `_MAX_ROWS = 200` 이 줄을 하나씩 자른다. 무리 중간에서 잘리면 머리줄만 있고 파일이 없는 조각이 남는다. 무리를 통째로 넣거나 통째로 뺀다.

## 실행 뒤 [보류한 N개 지우기]

### 왜 미리보기가 아니라 실행 뒤인가

`undo.py` 첫 줄이 이렇다. *"파일을 지우지 않았기 때문에 되돌릴 수 있다."*
도움말은 이렇게 약속한다. *"미리보기: 무엇이 어디로 갈지 계산만 합니다. 파일을 하나도 건드리지 않습니다."*

미리보기 표에서 아이콘을 눌러 파일이 사라지면 두 가지가 동시에 깨진다. 실행 뒤에 지우면 둘 다 지킨다.

### 함정 — 폴더를 통째로 지우면 안 된다

`executor.py` 에 이런 실측 주석이 있다.

> 같은 초의 두 실행은 이 폴더를 공유한다(기록 파일만 `-2` 로 비켜 간다).

`.organize/trash/{run_id}/` 를 통째로 비우면 **다른 실행이 넣어 둔 파일까지 날아간다.** 실행 기록(journal)의 `quarantine` 항목 `final` 경로만 하나씩 지운다.

### 명세

| | |
|---|---|
| 자리 | 실행 결과 창(`_show_landed`) 안, **보류가 있을 때만** |
| 단추 | `[보류한 5개 지우기]` |
| 확인 문구 | "5개를 완전히 지웁니다. 되돌릴 수 없고, 이 실행의 [되돌리기] 로도 되살릴 수 없습니다." |
| 지우는 대상 | 이번 실행 기록의 `quarantine` 항목 `final` 경로만 |
| 되돌리기 | 끄지 않는다 — 옮긴 것은 여전히 되돌아간다. 보류만 못 되살아난다 |
| 못 지운 파일 | 조용히 넘기지 않는다. `PurgeResult.messages` 에 담아 결과 창의 안내 목록(`_show_messages`)으로 띄운다 |

### 코드 자리

`organize/core/purge.py` 를 새로 만든다. 창은 그리기만 한다는 규칙 그대로다.

```python
@dataclass
class PurgeResult:
    removed: int = 0
    failed: int = 0
    messages: list[str] = field(default_factory=list)

def purge_run(root: Path, run_id: str) -> PurgeResult:
    """그 실행이 보류시킨 파일만 지운다. **폴더를 통째로 지우지 않는다.**"""
```

지운 뒤 빈 `.organize/trash/{run_id}/` 는 `undo.py` 의 정리 규칙과 같이 **비어 있을 때만** 치운다.

## 경계

| 상황 | 어떻게 |
|---|---|
| 무리가 아닌 보류(`keeper` 없음) | 머리줄 없이 그대로 한 줄 |
| 남기는 파일이 정리 대상 폴더 밖 | 전체 경로를 보여준다(상대 경로가 안 나온다) |
| 파일이 이미 없어져 `stat` 실패 | 수정일·크기 자리를 「—」로. 줄은 그린다 |
| 매체가 빠진 경로 | 링크로 그리지 않는다(`openable` 과 같은 규칙) |
| 지울 파일이 이미 없음 | 실패가 아니다. 이미 목적이 이뤄졌다 |
| 실행 기록을 못 읽음 | 지우지 않고 한국어로 알린다 |

## 테스트

| 무엇 | 어떻게 |
|---|---|
| `group_rows` | 순수 함수 — 창 없이. 무리 묶기 · 순서 · `keeper` 없는 줄 |
| `Action.keeper` | dedup 이 채우는지, 한 무리는 같은 `keeper` 인지 |
| 줄 수 제한 | 무리 중간에서 안 잘리는지 |
| `reveal_file` | OS 별 명령 · WSL 경로 변환 · 못 여는 경우 한국어 오류 |
| `purge_run` | **이번 실행 것만** 지워지고 다른 실행 것은 남는지 |
| 비운 뒤 되돌리기 | 옮김은 되돌아가고 보류는 실패로 남는지(죽지 않는지) |
| 진짜 창 | 미리보기 → 무리 캡처 → 실행 → 비우기 → 캡처로 확인 |
